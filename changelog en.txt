3.0.3
## Additions
Special Moves: the move dropdown of each slot is now a search popup inside the editor with every special move (1,299), searchable by name in any language or by ID
Special Moves: a Move List button to browse every move and watch its video, even without the game open
Special Moves: move names in Japanese, English or Spanish, picked with the Language filter like in the Spirit List. Names come from the official Player Codex and the Inazuma Eleven wikis; the few with no official name are translated and marked with *
Special Moves: each move's element (Fire, Forest, Wind, Mountain or Neutral) and an Element filter, shared with the slot lists
Special Moves: a preview button on every move and slot that plays its official video inside the editor (with its variants, e.g. Shot / Shot Block)

## Improvements
What's New (Special Moves): the move videos now open straight away instead of searching the Player Codex
Tool Menu: when the game was opened with Easy Anti-Cheat, the status now says so and what to do instead of "Failed to attach"

## Bug Fixes
Fixed the editor not finding the game when Steam keeps an old empty game folder in another library ("EACLauncher.exe not found")
Fixed the game being left without its EACLauncher.exe when a previous swap was interrupted: it is restored from the backup
Fixed the EAC launcher never being swapped when the editor was opened with the game already running: it is swapped as soon as the game closes
